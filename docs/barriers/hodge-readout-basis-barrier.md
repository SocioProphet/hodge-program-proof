## Purpose

This note attaches the coordinate-basis vs readout-basis involution pattern to the Hodge proof-program scaffold.

The local barrier statement is:

```text
Hodge-theoretic involution is not algebraic-cycle selectivity.
```

## Local interpretation

Hodge structures contain involutive and balancing symmetries, including complex conjugation, Hodge star variants, and Weil-operator behavior. These structures organize cohomology and identify Hodge-type decompositions, but they do not by themselves identify algebraic cycle classes.

The Hodge-conjecture-shaped readout problem is:

```text
rational (p,p)-class
-> algebraic cycle direction
```

Any technique that operates only on the full `H^{p,p}` space without identifying the algebraic-cycle readout direction remains a coordinate-basis method for this purpose.

## Guardrail

The correct local use of the cross-repo pattern is:

```text
involution: Hodge star / Weil operator / conjugation structure
selectivity: identification of rational (p,p)-classes coming from algebraic cycles
readout basis: algebraic-cycle directions, not merely cohomological coordinates
```
