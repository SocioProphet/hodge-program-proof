# Hodge Claim Boundary

Status: controlling doctrine for the Hodge Program Proof repository.

## Purpose

This document prevents Hodge-originated material from being diluted, inflated, or misclassified.

The program may study objects that touch Tate, Beilinson, Bloch–Kato, Yang–Mills, BSD, RH, proof dynamics, Temporal Mechanics, or Lawful Learning. Those objects remain genealogically attached to the Hodge program when they enter through Hodge-theoretic questions. They must still be classified by mathematical distance from the Hodge core.

## Core rule

Preserve origin. Classify distance. Do not bastardize the programs by flattening them into one undifferentiated claim.

## Allowed labels

- `core-hodge`: algebraic cycles, Hodge classes, generalized Hodge, standard conjectures, Lefschetz/Künneth/Hodge-index structures.
- `hodge-arithmetic`: Tate, Mumford–Tate, Beilinson, Bloch–Beilinson, Bloch–Kato, Fontaine–Mazur, periods, regulators, torsion obstructions.
- `hodge-method`: comparison isomorphisms, Deligne cohomology, regulator maps, finite monodromy, torsion shadows, obstruction registries, evidence ledgers.
- `hodge-fallout`: material that entered through Hodge but is distant, methodological, or cross-programmatic.
- `out-of-scope`: material not yet connected by a written Hodge-origin path.

## Forbidden promotions

The following promotions are forbidden unless supported by a specific theorem or cited literature result:

1. Hodge-originated material -> proof of Hodge.
2. Deligne cohomology class -> algebraic cycle.
3. finite monodromy / torsion character -> Tate or Mumford–Tate result.
4. regulator symbol -> Beilinson conjecture evidence.
5. analogy with YM/BSD/RH -> Hodge evidence.
6. comparison diagram -> motivic theorem.
7. source packet reference -> proof obligation closure.

## Claim levels

- `observation`: descriptive alignment or taxonomy.
- `definition`: formal object introduced in this repo.
- `lemma`: locally proved statement inside the repo.
- `theorem`: proved statement with all dependencies recorded.
- `conjecture`: explicit unproved statement.
- `program-goal`: strategic target, not a claim.
- `non-claim`: explicitly prohibited inference.

## Required language for distant fallout

When a topic is distant but genealogically Hodge-originated, use language like:

> This is Hodge-originated fallout, not a Hodge-theoretic claim. The connection is methodological/genealogical unless and until a specific Hodge-theoretic structure is constructed.
